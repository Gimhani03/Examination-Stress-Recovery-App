# Calendar Event Management Backend

## Overview

This backend provides comprehensive functionality for managing calendar events in the Flutter application. It includes a complete CRUD (Create, Read, Update, Delete) system for events with Supabase integration.

## Architecture

### Components

#### 1. **EventService** (`lib/services/event_service.dart`)
The core service layer that handles all database operations with Supabase.

**Key Methods:**
- `addEvent()` - Create a new event
- `getEventsForDate()` - Retrieve events for a specific date
- `getEventsForRange()` - Retrieve events for a date range (e.g., monthly view)
- `getEventById()` - Get a specific event by ID
- `updateEvent()` - Modify an existing event
- `deleteEvent()` - Remove an event
- `getUpcomingEvents()` - Get upcoming events with pagination

#### 2. **Event Model** (`lib/models/event_model.dart`)
A strongly-typed data model for events with serialization support.

**Properties:**
- `id` - Unique identifier (generated by Supabase)
- `userId` - Reference to the event owner
- `title` - Event name/title
- `eventDate` - Date of the event
- `time` - Time of the event (e.g., "9:00 AM")
- `description` - Optional event details
- `location` - Optional event location
- `createdAt` - Timestamp of creation
- `updatedAt` - Timestamp of last update

**Methods:**
- `Event.fromDatabase()` - Factory constructor for deserializing from Supabase
- `toDatabase()` - Serialize to a map for database operations
- `copyWith()` - Create a modified copy of the event

#### 3. **EventProvider** (`lib/providers/event_provider.dart`)
State management provider using ChangeNotifier for reactive UI updates.

**Key Methods:**
- `getEventsForDate()` - Load and cache events for a specific date
- `getEventsForMonth()` - Load all events for a month, organized by date
- `addEvent()` - Add a new event with UI feedback
- `updateEvent()` - Modify an event with validation
- `deleteEvent()` - Remove an event with confirmation
- `getUpcomingEvents()` - Fetch upcoming events
- `getEventsByDate()` - Filter events by date from cache

**State Properties:**
- `events` - List of all loaded events
- `isLoading` - Loading state indicator
- `error` - Error message if any
- `selectedDate` - Currently selected date

#### 4. **Calendar Screen Integration** (`lib/calendar_screen.dart`)
Updated UI layer that integrates with the event service.

**Features:**
- Real-time event display in calendar grid
- Add event dialog with enhanced UI
- Delete event with confirmation
- Month navigation with event loading
- Visual indicators for events on calendar dates
- Event listing by selected date
- Error handling with user feedback

## Database Schema

The `events` table in Supabase should have the following structure:

```sql
CREATE TABLE events (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  event_date DATE NOT NULL,
  time VARCHAR(20),
  description TEXT,
  location TEXT,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- Indexes for better performance
CREATE INDEX events_user_id_date_idx ON events(user_id, event_date);
CREATE INDEX events_user_id_upcoming_idx ON events(user_id, event_date DESC);
```

## Usage Examples

### Adding an Event

```dart
final eventService = EventService();
await eventService.addEvent(
  title: 'Team Meeting',
  eventDate: DateTime(2026, 2, 15),
  time: '2:00 PM',
  description: 'Weekly team sync',
  location: 'Conference Room A',
);
```

### Retrieving Events for a Month

```dart
final eventService = EventService();
final start = DateTime(2026, 2, 1);
final end = DateTime(2026, 2, 28);

final events = await eventService.getEventsForRange(
  start: start,
  end: end,
);
```

### Using EventProvider with Consumer

```dart
// Listen to events
Consumer<EventProvider>(
  builder: (context, eventProvider, child) {
    return ListView.builder(
      itemCount: eventProvider.events.length,
      itemBuilder: (context, index) {
        final event = eventProvider.events[index];
        return ListTile(
          title: Text(event.title),
          subtitle: Text(event.time),
        );
      },
    );
  },
)

// Add an event
final success = await eventProvider.addEvent(
  title: 'Important Event',
  eventDate: DateTime.now(),
  time: '3:00 PM',
);
```

## Error Handling

All methods include comprehensive error handling:

1. **Authentication Errors** - Throws `AuthException` when user is not signed in
2. **Database Errors** - Catches Supabase exceptions with user-friendly messages
3. **Validation Errors** - Validates required fields before database operations
4. **UI Feedback** - Shows SnackBar notifications for success/failure

## Date Formatting

Events use standardized date formatting:
- **Database Format**: `YYYY-MM-DD` (ISO 8601)
- **Display Format**: User-friendly formats based on locale
- **Time Format**: Flexible format (e.g., "9:00 AM", "14:30")

## Performance Considerations

1. **Pagination** - `getUpcomingEvents()` supports limiting results
2. **Indexed Queries** - Database queries use indexed columns (user_id, event_date)
3. **Batch Loading** - Month view loads all events in one query
4. **Efficient Caching** - EventProvider caches events to avoid redundant queries

## Security

1. **User Isolation** - All queries filter by `user_id` to ensure data privacy
2. **Authentication Check** - Every operation verifies the current user
3. **Row-Level Security** - Supabase RLS policies should enforce user isolation
4. **Input Validation** - All user inputs are validated before database operations

## Troubleshooting

### Events not displaying
- Check if the user is authenticated
- Verify the events table exists in Supabase
- Check network connection and Supabase status

### Add event dialog not working
- Ensure title field is not empty
- Verify date is valid
- Check console for error messages

### Delete operation failing
- Confirm event ID exists
- Verify user has permission to delete
- Check Supabase RLS policies
